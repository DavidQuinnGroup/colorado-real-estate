# Market Intelligence Semantics, Sufficiency, and Property Criteria Foundation Certification

## Certification Scope

`PROJECT_ATLAS_MARKET_INTELLIGENCE_SEMANTICS_SUFFICIENCY_AND_PROPERTY_CRITERIA_FOUNDATION_MVV`

The package establishes internal semantic governance, a deterministic intelligence-gap artifact, a reusable Agent preparation heading hierarchy, and a session-only property criteria foundation.

## Certified Controls

- Inventory, days-on-market, and price signals are explicitly classified `METRIC_SEMANTICS_UNRESOLVED` when admitted repository evidence does not define their source semantics.
- `Average Days on Market`, `Median Days on Market`, `Active Listings`, `Median List Price`, and `Median Closed-Sale Price` are not asserted without admitted authoritative definitions.
- Market Preparation and Market Update expose semantic limitations rather than silently upgrading generic repository strings.
- Generated briefing major sections use the shared 20-22px mobile / 24-28px desktop hierarchy; selection-group hierarchy remains 22px mobile / 30px desktop.
- Buyer, Seller, Listing, and Property preparation reuse one local-only Property Criteria Profile vocabulary while retaining distinct buyer-preference and seller/listing/property-fact contexts.
- Criteria remain session-only and cannot create a customer profile, saved search, provider query, MLS activity, persistence, recommendation, valuation, or segmentation.

## Non-Authorization

This certification does not authorize source admission, Registry promotion, provider activity, database persistence, MLS/IRES access, historical data acquisition, market computation, Typesense, CRM, customer data, communications, public rendering, charts, reporting, export, deployment, or any property/search mutation.

## Next Authorization Gate

`AUTHORITATIVE_MARKET_METRIC_METHODOLOGY_AND_HISTORICAL_EVIDENCE_READINESS_REVIEW_REQUIRED`

The next package must establish source rights, methodology, freshness, comparable historical observations, and admission before any new market intelligence, segmentation, comparative reporting, or runtime activation is proposed.
