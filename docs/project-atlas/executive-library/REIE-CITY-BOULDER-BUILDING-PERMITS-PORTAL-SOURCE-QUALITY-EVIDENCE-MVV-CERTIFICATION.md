# REIE City Boulder Building Permits Portal Source Quality Evidence MVV Certification

## Scope

This MVV certifies a source-specific, certification-only Source Quality evidence package for:

`SRC-CITY-BOULDER-BUILDING-PERMITS-PORTAL`

It does not inspect, retrieve, automate, scrape, display, activate, or legally approve portal content.

## Canonical conversion

The package uses `convertPublicRecordStructuredEvidence` with source class `MUNICIPAL_PERMIT_PORTAL` and exact source confirmation. It produces one canonical certification linkage and flows through Evidence Normalization, Source Quality Control, and Summary Assembly.

## Structured input

The sole evidence input is a controlled `CERTIFICATION_REFERENCE` bound to the exact portal source. It contains no portal page, HTML, terms, correspondence, PDF, endpoint data, or raw permit records.

## Evidence posture

- Field sensitivity: `RESTRICTED_OR_UNREVIEWED` as governance metadata only.
- Rights: `UNKNOWN`.
- Technical access: `UNKNOWN`.
- Freshness: `UNKNOWN`.
- Attribution: `UNKNOWN`.
- Provenance: `UNKNOWN` / incomplete.
- Normalization and Control: `INSUFFICIENT_EVIDENCE` with preserved known gaps.
- Assembly: accepted as a sparse one-source request.
- Eligibility: `READY_WITH_KNOWN_GAPS`.

Eligibility means governed evidence exists for later Source Quality and Manifest decision review. It does not mean provider confirmation, access, API availability, automation, currentness, completeness, activation, retrieval, scraping, customer display, or legal approval.

## Registry and channel boundaries

Registry posture remains `AWAITING_PROVIDER_CONFIRMATION`, `BLOCKED_NOT_AUTHORIZED`, and claim-ineligible. Evidence does not alter Registry authority and is not inherited from City Open Data, Boulder County Accela, Permit Candidates, Assessor, or Treasurer.

## Protected boundaries

No portal, City website, endpoint, API, correspondence, PDF, protected county artifact, database, provider, credential, CRM, Search, Typesense, route, or UI is used.

## Later work

Any future human-reviewed findings remain separate. Any Operational Manifest inclusion requires a separate decision review.
