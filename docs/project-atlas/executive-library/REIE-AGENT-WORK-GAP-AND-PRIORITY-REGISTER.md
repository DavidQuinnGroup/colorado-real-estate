## Priority Model

Opportunities are ranked qualitatively using manual labor intensity, repetition/frequency, number of agents/customers affected, customer decision value, existing architectural leverage, evidence/source availability, implementation complexity, compliance/fair-housing/privacy risk, protected-system impact, duplication risk, and the amount of human judgment that should remain human.

- `P0`: high-value / high-leverage next candidate.
- `P1`: strong future candidate.
- `P2`: useful but lower priority.
- `P3`: defer / human-dominant / low automation value.
- `BLOCKED`: source, rights, architecture, or compliance dependency must be resolved first.
