differs from reported context, changed City or property discussion context,
changed priorities, material professional verification questions, and dated
market context where admitted.

This repairs the empty Buyer panel and applies the same discipline to Buyer,
Market, Place, and Property briefings.

transfer. They preserve the existing Human Agent session boundary; the target
