## Candidates Evaluated

### A. Close Wave 1B And Transition To Wave 1A

Status: `SELECTED`

This candidate provides the strongest customer and enterprise leverage because the original high-risk Search interaction defects have been certified and closed, while homepage and global hierarchy remain the first broad customer impression.

Wave 1A is the proper next DXT sequence from the Wave 1 Decision Architecture Plan. It owns Homepage Invitation and Global Hierarchy, including the homepage's role as invitation rather than manual, first-screen hierarchy, directional-heading standards, global page orientation, CTA hierarchy, whitespace, pacing, and restrained explanatory copy.

### B. Property Detail Context Preservation Phase 2

Status: `DEFERRED`

Phase 2 remains useful but no longer outranks Wave 1A. The remaining work includes map bounds, zoom, list scroll, preview reopening, selected-card focus, and return-position refinement. Those would improve continuity for some Search-to-property loops, but the current URL-backed return context is sufficient for bounded customer recovery.

Risks include URL/history complexity, stale-state handling, accessibility complexity, and a stronger chance of refinement-level gains rather than broad customer transformation.

### C. Another Bounded Search Or Property Phase

Status: `REJECTED_FOR_NOW`

Repository evidence supports unresolved Search/property refinements, including property page decision hierarchy, empty/degraded state refinement, and property-detail decision handoff. None is currently proven to outrank homepage/global hierarchy after the four certified Wave 1B phases.

This candidate should re-enter consideration only if a concrete production defect is observed that materially blocks property discovery.

### D. Transition Directly To Wave 1C Buyer And Seller Journey Simplification

Status: `DEFERRED_AFTER_WAVE_1A`

Buyer and Seller surfaces contain visible density, competing CTAs, long explanatory paths, and uneven heading hierarchy. Buyer includes multiple decision-workspace, financing, cohesion, and guidance sections. Seller combines preparation, market context, contact routing, seller readiness, home-worth context, and intake behavior.

Wave 1C is high value, but Wave 1A should come first because global page hierarchy and homepage invitation standards will improve how Wave 1C is specified and prevent isolated buyer/seller redesign.

### E. DXT Program Pause

Status: `REJECTED`

A pause is not justified. Remaining problems are repository-supported, strategically sequenced, and bounded. Continuing with Wave 1A avoids drifting into Search diminishing returns while still advancing the certified DXT architecture.

## Wave 1B Completion Findings

Wave 1B originally targeted the highest-risk customer interaction defects in Search and property discovery. Those defects are now materially resolved:

- Search preview instability was resolved through click-first marker selection and pinned preview.
- Search workspace hierarchy was improved through a unified list/map shell and clearer Search orientation.
- Property return continuity was resolved within a bounded URL-backed Search-origin context model.
- Search map visual inconsistency was resolved within the existing OpenTopoMap provider posture.

Remaining Wave 1B limitations are accepted as deferred:

- full map-bounds restoration;
- zoom restoration;
- list-scroll restoration;
- preview reopening;
- selected-card focus;
- desktop, tablet, and mobile return-position refinement;
- deeper property page decision hierarchy.

These are no longer the highest-leverage DXT issues.

## Property Context Phase 2 Findings

Property Detail Context Preservation Phase 2 would provide continuity polish for customers moving from Search to property detail and back. It could reduce repeated orientation work in longer browsing sessions.

However, the certified bounded handoff already covers the essential decision need: customers can return to validated internal Search context with supported criteria and safe direct-entry behavior. Phase 2 introduces higher state-complexity risk than Wave 1A and would serve a narrower interaction loop.

Recommendation: keep Phase 2 deferred until Wave 1A establishes global hierarchy and until production evidence shows return-position friction remains material.

## Additional Search / Property Findings

Additional Search/property refinement should not be invented merely to continue Wave 1B.

Repository-supported future topics include:

- property page decision hierarchy;
- selected-property preview refinement;
- Search empty/degraded state refinement;
- property-detail decision handoff.

None currently outranks the homepage/global hierarchy gap because Search has already received four certified DXT phases and now provides a materially stronger property-discovery workspace.

## Homepage And Global Hierarchy Findings

Repository evidence supports Wave 1A as the next highest-leverage direction:

- Homepage already has a strong hero invitation and primary Search CTA.
- Below the hero, the page still contains several substantial explanatory sections: journey paths, decision continuity, Why REIE, Search invitation, community/place context, Grand Plan, David Quinn positioning, schema/FAQ content, and multiple continuations.
- The homepage still risks becoming a manual below the hero rather than remaining a premium invitation into one clear next decision.
- Global directional hierarchy remains inconsistent across surfaces, with many pages using similar visual weight for eyebrows, directional headings, supporting headings, body copy, CTA clusters, panels, and trust language.
- Global headers and page orientation patterns do not yet consistently feel like one premium, intuitive product system.
- The Wave 1 Decision Architecture Plan explicitly identifies Homepage Invitation and Global Hierarchy as Wave 1A.

Wave 1A should include:

- post-hero simplification;

- consistent page orientation;
- section hierarchy;
- CTA hierarchy;
- whitespace and pacing;

## Diminishing-Returns Assessment

Continuing Wave 1B implementation now risks diminishing returns.

Wave 1B has already addressed the highest-risk Search interaction, workspace, return-context, and map visual-language defects. Additional Search/property work would likely improve refinement and continuity, but the next meaningful premium-experience leap comes from making the homepage and global hierarchy feel like a clearer invitation into REIE.

REIE should transition from Search repair to global decision invitation.
