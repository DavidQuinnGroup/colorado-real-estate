# Agent Consultation Unlimited Priority Focus Standard

## Canonical Rule

Preparation-topic selections control emphasis, not access to consultation knowledge. All applicable topics may be selected. Selected topics receive Priority Focus treatment while the complete consultation playbook remains available.

## Application

Buyer Preparation and Seller Preparation require their governed minimum selection for a useful briefing, but impose no maximum-topic ceiling. Selection order does not change the prepared questions or playbook emphasis. The briefing, full playbook, professional checkpoints, agenda, and next actions remain available on the same preparation page.

The Executive Briefing may retain its separate high-value question limit for readability. That presentation limit does not limit selections or remove any selected topic from the complete consultation playbook.

## Boundaries

This is an internal Agent interaction standard. It authorizes no provider activity, customer-data handling, persistence, recommendation, suitability conclusion, protected-class inference, property assignment, or public activation.
