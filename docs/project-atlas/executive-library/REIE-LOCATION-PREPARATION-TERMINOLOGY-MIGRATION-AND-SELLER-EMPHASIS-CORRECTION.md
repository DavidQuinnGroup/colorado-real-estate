# Location Preparation Terminology Migration and Seller Emphasis Correction

## Product Taxonomy

The Agent Workspace presents Buyer Preparation, Seller Preparation, Location Preparation, Property Preparation, and Market Preparation. Location Preparation remains the existing private `/agent/prepare/place` capability so its authorization, return path, and certified city behavior remain unchanged.

Location Preparation provides geographic and local-context orientation. Property Preparation owns address and asset diligence. Market Preparation owns dated market evidence. This terminology change does not authorize public geography, new location data, provider activity, or customer context.

## Seller Selection Model

Seller Preparation requires a consultation position and at least two selected topics. There is no maximum topic count: all supported topics may be selected and receive Priority Focus treatment. The full Seller playbook remains available for every admitted briefing, while selected topics control emphasis and the prioritized question set.
