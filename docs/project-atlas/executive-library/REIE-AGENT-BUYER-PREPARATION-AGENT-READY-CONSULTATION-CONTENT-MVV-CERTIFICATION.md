## Scope

This MVV turns the internal Agent Buyer Preparation consultation playbook into
an agent-ready work product. It provides neutral questions, talking points,
facts to confirm, professional checkpoints, expected outcomes, and a
six-step consultation agenda for the existing protected Agent-only Buyer
Preparation route.

The work product is derived only from explicit preparation selections and
already governed internal composition. It retains the concise Executive
Briefing as the first pass and moves the detailed material behind progressive
disclosure.

## Certified Conversation Contract

The playbook supports a practical consultation about purchase objective,
timing, property criteria, trade-offs, financing preparation, search strategy,
Place orientation, buying process, offer-preparation education, professional
questions, representation process, and next-step readiness.

Each expanded consultation surface identifies:

- Key questions the Agent may use naturally.
- Neutral talking points and process explanations.
- Facts the Agent should confirm rather than infer.
- The professional verification lane where one applies.
- The bounded outcome of the conversation segment.

The selected 3-6 month horizon produces neutral follow-up questions about
explicit milestones, flexibility, and what could move timing earlier or later.
Louisville remains City orientation only. It is not a neighborhood,
property-specific, market-observation, or suitability conclusion.

## Boundaries

This MVV does not create a customer profile, persist selections, mutate a
session, retrieve or activate providers, access IRES, use current market
facts, create a Saved Search, select a professional, communicate with a
provider, prepare an offer, calculate affordability, make a qualification
conclusion, give legal or lending advice, or establish a representation
relationship.

Financing material is explicitly separated into client-reported context,
Agent process questions, and lender verification. Fair Housing and
non-suitability limits remain in force: questions use stated decision and
objective property criteria without inferring protected characteristics,
household composition, motivation, or preferred area.

Existing exact Agent authorization, ephemeral session-only input behavior,
and the narrow `/agent/prepare/buyer` route remain unchanged. Contextual
actions use existing Place and Property Preparation routes without query
parameters, fragments, or unsupported state transfer.

## Product Standard

This certification applies the Agent-Ready Work Product Principle in the REIE
Product Experience North Star: governed Agent capabilities should produce
usable consultation material where professional boundaries permit, rather
than merely listing topics to prepare.

The work product assists professional judgment. It is not a recommendation,
professional determination, automatic workflow, public feature, or a release
of any protected-system authority.
