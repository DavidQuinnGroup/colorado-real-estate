## 4. Fail-Closed Implementation

The remediation adds an explicit city-market public-route guard:

- `CityData.publicMarketRoute?: boolean`
- `isCityMarketRoutePublic(city)`

The Niwot compatibility city record remains present but is explicitly marked:

- `publicMarketRoute: false`

The dynamic city-market route now:

- excludes non-public city records from `generateStaticParams()`;
- returns not-found metadata for non-public city records;
- calls `notFound()` for direct access to non-public city-market slugs.

This causes `/market/niwot-co-housing-market` to fail closed through the repository-supported not-found path while preserving authorized city-market routes.
