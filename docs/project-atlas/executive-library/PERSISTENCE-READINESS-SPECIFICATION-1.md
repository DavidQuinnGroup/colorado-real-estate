# Persistence Readiness Specification(tm) 1.0

Status: `PERSISTENCE_READINESS_SPECIFICATION_CREATED_NOT_AUTHORIZED`

Date: July 29, 2026

## Executive Summary

Existing persistence is not sufficient for durable external-source evidence storage. A future additive migration is required, but no Prisma, schema, database, or provider changes are authorized in this program.

## Minimum Additive Persistence

Future persistence should include:

- Source identity
- Acquisition run
- Raw evidence version
- Normalized observation
- Geographic subject
- Permitted use
- Public-display eligibility
- Freshness
- Confidence
- Conflict and supersession
- Imagery rights where applicable

## Existing Persistence Reuse

Existing repository-local market and registry data can continue to seed dry-run evidence candidates. It should not be treated as durable external-source evidence storage.

## Future Migration Required

Yes. A future migration is required before external source activation or durable evidence writes.

## Prohibited Until Authorized

- Prisma/schema migration
- Provider execution
- Durable external-source writes
- Customer-visible partial evidence
- Public GIS activation
- AI-generated customer claims
- Telemetry or personalization activation

This specification is not legal advice and does not issue final legal conclusions.
