# REIE DXT Wave 1A Homepage Invitation And Global Hierarchy Product Specification

Program: REIE Decision Experience Transformation (DXT 1.0)

Phase: Wave 1A - Homepage Invitation and Global Hierarchy Product Specification

Status: `REIE_DXT_WAVE_1A_HOMEPAGE_INVITATION_AND_GLOBAL_HIERARCHY_SPECIFICATION_READY`

Date: August 2, 2026

## 1. Executive Product Decision

The first bounded Wave 1A implementation phase should be:

`HOMEPAGE_INVITATION_AND_POST_HERO_SIMPLIFICATION`

The homepage should become an invitation into REIE, not a compressed manual for the entire product. The strongest next customer value is to preserve the successful first-screen Search invitation, simplify the post-hero sequence, reduce competing concepts, establish clearer directional hierarchy, and define a reusable global hierarchy model without starting a site-wide redesign.

Implementation is not authorized by this specification.

## 2. Governing Product Question

Why should I begin here, and what should I do next?

Every homepage section must answer that question or support it at the correct depth. If a section primarily explains the product before the customer has expressed intent, it should be simplified, moved lower, progressively disclosed, moved to a destination page, or removed.

## 3. Current Customer Problem

The current homepage has a strong opening concept but becomes too informational and manual-like below the hero.

Customers experience:

- too many concepts introduced too quickly;
- insufficient distinction between directional headings and body copy;
- dense clusters of explanatory content;
- multiple similarly weighted actions;
- unclear progression after the first Search invitation;
- insufficient emotional and visual pacing;
- inconsistent hierarchy patterns across major customer-facing pages;
- sections that explain the product before the customer has expressed intent;
- a homepage that behaves partly like a manual rather than an invitation.

## 5. Section Dispositions

Disposition standard:

- KEEP: directly supports the homepage governing question.
- SIMPLIFY: valuable but too dense or equally weighted.
- MERGE: overlaps with another section.
- MOVE_LOWER: useful after higher-intent sections.
- PROGRESSIVELY_DISCLOSE: useful after customer choice.
- MOVE_TO_DESTINATION: belongs on a deeper route.
- REMOVE: does not materially improve the decision.
- EXTERNAL_REVIEW_HOLD: not in Wave 1A implementation authority.

| Section / Pattern | Disposition | Reason |
| --- | --- | --- |
| Hero | KEEP_AND_REFINE | The hero already functions as the invitation and should keep one emotional promise and one dominant Search action. |
| Hero secondary `Why REIE` action | SIMPLIFY | Useful, but should remain clearly subordinate to Search. |
| Search invitation | KEEP_AND_ELEVATE | Search remains the primary beginning action. It should become the clearest post-hero continuation. |
| `Three paths` decision section | SIMPLIFY | Search, Buyer, and Seller are useful, but equal card treatment can overstate secondary routes before Search intent. |
| Buyer entry | KEEP_AS_SECONDARY_PATH | Buyer is a real decision path but should not compete with the primary Search invitation. |
| Seller entry | KEEP_AS_SECONDARY_PATH | Seller is a real decision path but should not compete with the primary Search invitation. |
| Explore / Market entry | KEEP_LOWER | Place and market context matters after primary orientation. |
| REIE difference / value proof | MERGE_AND_SIMPLIFY | Useful proof should be selective and concise, not a second product explanation. |
| Colorado Discovery Preview | MERGE_WITH_SEARCH_INVITATION | It supports Search orientation and should not feel like a separate concept. |
| Market and neighborhood previews | MOVE_LOWER | Useful after the customer understands the primary start path. |
| Grand Plan | MOVE_LOWER | Differentiating, but it is a deeper journey after initial orientation. |
| Advisory transition | MOVE_LOWER | Advisory belongs near the close, after discovery and preparation paths are clear. |
| Trust/disclosure content | KEEP_AT_SUPPORTING_DEPTH | Essential boundaries should remain visible where relevant without leading the emotional experience. |
| Final CTA | KEEP_AND_RESTRAIN | Close with a clear continuation, not a dense action cluster. |
| Footer transition | OUT_OF_SCOPE | Footer remains preserved unless separately authorized. |
| Brokerage disclosure | EXTERNAL_REVIEW_HOLD | `EXTERNAL_COMPASS_MARKETING_REVIEW_PENDING`; do not modify. |

DXT section test:

If this disappeared, would the customer make a worse decision?

Application:

- Hero and Search invitation pass the test.
- Buyer/Seller paths pass as secondary choices.
- REIE proof passes only if selective.
- Market, Grand Plan, and Advisory pass only lower in the sequence.
- Repetitive explanations fail and should be merged or moved.

## 6. Target Homepage Journey

Target sequence:

1. Invitation
2. Orientation
3. One primary discovery action
4. Small number of clearly differentiated decision paths
5. Selective proof of REIE value
6. Calm transition into deeper destinations
7. Trust and professional boundaries at the appropriate level
8. Restrained close

The homepage should feel like the beginning of a premium decision product:

- clear first promise;
- low cognitive load;
- emotionally calm;
- visibly high confidence;
- sparse enough to invite action;
- deep enough to prove REIE is useful;
- never a product directory.

## 7. First-Viewport Specification

First viewport must include:

- one emotional promise;
- one clear value proposition;
- one dominant Search or discovery action;
- no dense product explanation;
- no competing equal-weight CTA cluster;
- immediate visual understanding;
- clear relationship to David Quinn Group and REIE;
- brokerage disclosure unchanged and outside implementation authority.

First viewport must not include:

- full product directory;
- dense trust wall;
- multiple equally weighted journeys;
- expanded REIE methodology;
- buyer/seller/market/advisory card walls;
- unsupported claims of superiority.

## 8. Post-Hero Sequence

Recommended post-hero architecture:

1. Primary Search invitation and light discovery orientation.
2. Simplified decision paths: Search dominant, Buyer and Seller subordinate.
3. Selective REIE value proof: three or fewer proof points, with strong heading/body distinction.
4. Place and market continuation as a lower-intensity bridge.
5. Grand Plan as a deeper reflective destination.
6. Advisory/David Quinn close as a restrained final continuation.

Maximum primary sections:

- one hero;
- one immediate Search/discovery continuation;
- one decision-path section;
- one proof section;
- one deeper-destination section;
- one closing advisory section.

If a section cannot explain why it belongs in this sequence, it should move to a destination page or be removed.

## 9. Three-Paths Model

Search, Buyer, and Seller remain appropriate homepage paths, but they should not all receive equal visual dominance.

Recommended model:

- Search: primary path and homepage's dominant continuation.
- Buyer: secondary route for preparedness and financing/readiness questions.
- Seller: secondary route for preparation, pricing context, and property review.

Explore/Market should not become a fourth equal path. It should appear as a lower continuation after Search and decision-path orientation.

The section should be editorial and simplified, not a dense interactive directory. Each path should answer a real customer decision:

- Search: Which homes deserve my attention?
- Buyer: Am I prepared to buy?
- Seller: What should I prepare before going to market?

## 10. REIE Value-Proof Model

Value proof should show why REIE is different without explaining the entire platform.

Recommended proof categories:

- Context before clicks.
- Evidence with limits.
- Professional judgment.

Rules:

- three proof points maximum in the first implementation phase;
- short body copy;
- no internal governance language;
- no unsupported superiority claims;
- no automated certainty;
- no product-feature inventory.

## 11. Global Hierarchy Standard

Reusable hierarchy roles for future customer-facing pages:

1. Page orientation
2. Governing decision question
3. Hero or opening promise
4. Directional heading
5. Supporting heading
6. Body copy
7. Proof or evidence
8. Primary action
9. Secondary continuation
10. Disclosure or limitation
11. Metadata

Differentiation should be dramatic but restrained through:

- scale;
- weight;
- spacing;
- line length;
- placement;
- contrast;
- section rhythm.

This is a hierarchy standard, not authorization for a site-wide redesign.

## 12. Directional-Heading Standard

Heading roles:

- Page-level decision heading: states the page's main decision promise.
- Major directional heading: tells the customer what decision stage they are entering.
- Supporting heading: names a subtopic or proof point.
- Explanatory copy: supports, never competes with, the heading.
- Action label: verb-led and concise.
- Disclosure copy: limitation-forward and visually subordinate, but readable.

Responsive relationships:

- page-level headings should clearly dominate body copy;
- major directional headings should be visibly distinct from supporting headings;
- body copy should use controlled line length;
- action labels should read as commands, not additional headings;
- disclosure copy should remain adjacent to relevant claims without becoming the emotional lead.

Avoid arbitrary exact values unless existing implementation patterns support them. The future implementation should reuse existing homepage typography patterns where they work and simplify where they create uniform density.

## 13. CTA Hierarchy

CTA rules:

- one primary action per major viewport;
- one subordinate secondary action only when necessary;
- tertiary continuations only after customer intent;
- no dense CTA clusters;
- no competing buttons of equal visual weight;
- clear verb-led labels;
- route continuity using existing destinations;
- mobile stacking with primary action first.

Homepage primary CTA:

- Search / discovery action to `/search`.

Secondary CTAs:

- Buyer and Seller guidance after the Search path is established.
- Market, Grand Plan, and Advisory lower in the sequence.

## 14. Whitespace And Section Rhythm

Wave 1A should specify intentional pacing:

- clear separation among decision stages;
- fewer bordered containers;
- restrained tonal fields;
- floating editorial text where appropriate;
- wider visual pauses;
- controlled line length;
- fewer consecutive dense sections;
- no wall of similarly styled cards;
- clear beginning and end of each decision stage.

The homepage should feel composed, not sparse for its own sake. Whitespace should create confidence and help the customer understand what matters next.

## 15. Progressive Disclosure Model

Classification:

| Content | Placement |
| --- | --- |
| Emotional promise and Search action | `FIRST_VIEWPORT` |
| Search orientation and minimal discovery framing | `IMMEDIATE_POST_INTENT` |
| Buyer/Seller paths | `IMMEDIATE_POST_INTENT` |
| REIE proof points | `DEEPER_HOMEPAGE` |
| Market, neighborhood, Grand Plan, Advisory | `DEEPER_HOMEPAGE` |
| Detailed buyer/seller explanations | `DESTINATION_PAGE` |
| Full methodology, evidence depth, operational detail | `DESTINATION_PAGE` or `TRUST_OR_DISCLOSURE` |
| Trust/professional limits | `TRUST_OR_DISCLOSURE` |
| Redundant feature explanation | `REMOVE` |

Essential trust, fair-housing, evidence, professional-boundary, and brokerage obligations must not be removed. They should appear at the right depth and proximity.

## 16. Desktop Experience

At approximately `1440x1100`, the homepage should provide:

- premium editorial rhythm;
- dramatic hierarchy without oversized decoration;
- meaningful whitespace;
- selective imagery or visual proof only where justified;
- restrained section width;
- one dominant journey;
- no manual-like sequence of uniformly weighted modules;
- no dense card wall;
- no dashboard styling.

Desktop should use width to create calm and contrast, not to add more simultaneous choices.

## 17. Tablet Experience

- readable line lengths;
- intentional spacing;
- no crowded multi-column card wall;
- coherent CTA sequence;
- Search path first;
- Buyer/Seller continuation visible but subordinate.

Tablet should not inherit desktop density if it weakens scanning.

## 18. Mobile Experience

At approximately `390x844`, the homepage should provide:

- shorter copy;

Mobile is the strongest test of whether the homepage is an invitation or a manual.
