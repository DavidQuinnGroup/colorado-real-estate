Only bounded categories may enter a future source-locked draft input. General
model memory, unsourced web knowledge, hidden personalization, telemetry,

publication helper is invoked.

unknown rights, stale sources, missing claim boundary, specialist-review bypass,
prohibited claims, unsourced expansion, AI-generation attempts, and all public
effects. Existing Sundance route, sitemap, and article rendering files remain
unchanged.
