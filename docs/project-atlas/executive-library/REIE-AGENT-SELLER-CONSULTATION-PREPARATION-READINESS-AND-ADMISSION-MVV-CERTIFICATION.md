# REIE Agent Seller Consultation Preparation Readiness and Admission MVV Certification

## Scope

This MVV adds the exact private Agent route `/agent/prepare/seller`. It composes a Seller consultation preparation briefing from explicit, session-only selections. It does not create a Seller Lead, customer profile, property assignment, CRM record, task, email, provider request, source activation, deployment configuration, or public runtime feature.

## Admission and State

The request requires the exact `HUMAN_AGENT` / `AGENT` / `HUMAN_AGENT_SESSION` identity, capability, and route. It requires one governed consultation position and two through five governed Seller topics. Unknown timing, protected context, persistence, provider activity, protected-class or demographic inference, suitability conclusions, pricing recommendations, legal conclusions, and tax advice fail closed.

The client retains selections only in React component state. Preparation and update both remain on the exact Seller route. The generated briefing remains visible while selections are edited, then is explicitly refreshed by the Agent.

## Work Product and Boundaries

The composition provides an executive briefing, explicit evidence/context, questions worth asking, limitations, professional checkpoints, a Seller position/readiness section, property and market preparation, process roadmap, launch preparation, financial/proceeds boundaries, future offer-review education, representation/process checkpoints, six-step consultation agenda, and next-action plan.

Every expandable panel uses the shared `DisclosureStateIndicator`; its chevron derives from the native details state. Empty sections are not rendered. Market, property, title, lienholder, lender, insurance, tax, legal, HOA, municipal, county, inspection, and engineering questions remain verification checkpoints. Pricing remains an Agent professional judgment supported by admitted evidence, never an automated recommendation, forecast, or guarantee.

## Exact Authorization

`/agent/prepare/seller` is separately listed in the authorization registry, middleware matcher, login return-path allowlist, and Agent navigation. It is read-only and Agent-only. No generic `/agent/:path*` authorization has been introduced.

## Deterministic Certification

`npm run check:agent-seller-consultation-preparation` proves the route, title, input model, scenario fixture, timing vocabulary, fail-closed boundaries, same-page continuity, composition, playbook, agenda, contextual continuations, shared disclosure behavior, and absence of prohibited runtime or persistence dependencies.

Technical certification is conditional on the package validation run. Human certification remains pending Executive production review.
