## Current Doctrine

For an existing authorized professional source, PROJECT ATLAS may proceed with ordinary professional use when access is authorized, the proposed use is within the professional real-estate purpose, and no actual relevant restriction has been identified. This operational doctrine is not legal advice and cannot override applicable law, brokerage or MLS rules, source contracts, technical controls, or a later evidenced restriction.

Automation does not itself create a permission requirement. It may perform the same permitted retrieval, organization, calculation, synthesis, retention, and professional-preparation functions as the authorized Agent unless a cited restriction governs the automation or proposed use.

## Restriction-Triggered Decision Rule

An affected use is blocked only by a cited, applicable restriction trigger: explicit prohibition or permission requirement, automation or derived-work restriction, retention/deletion/termination requirement, public-display or redistribution restriction, unsatisfied attribution, technical/rate-limit policy, license conflict, material contractual ambiguity, or regulatory/brokerage conflict. No restriction is inferred from silence, an unanswered clarification inquiry, or an uncited assertion.

`NO_RESTRICTION_IDENTIFIED` is distinct from `MATERIALLY_AMBIGUOUS_CONTRACTUAL_TERM`. Material ambiguity requires a bounded clarification gate; it does not create unlimited rights. Public website display remains separately gated even when internal professional use is not permission-blocked.

## Raw, Derived, And Historical Boundaries

Raw source records, normalized facts, single-record derivations, current aggregate statistics, retained aggregate snapshots, historical comparisons, Agent synthesis, client-facing work product, and public display are separate categories. A restriction applies only to the categories it cites.

Retention is not presumed prohibited. Snapshot creation and raw retention remain blocked here by separate architecture and persistence gates, not by an invented permission failure. Historical comparisons remain blocked when the required historical evidence is absent. Source quality, field semantics, freshness, completeness, provenance, conflicts, Fair Housing, privacy, security, professional review, and public-trust controls remain independent gates.
