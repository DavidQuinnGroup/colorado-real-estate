V2 mobile containment, Dark mode, focus accessibility, profile family coherence, and the material hierarchy passed. ## V3 Canonical Correction

The Light canvas and root now use an explicit Light background color in addition to the atmospheric image. Ordinary Light surfaces and fields use near-white or cool-neutral values, while Dark remains isolated to the system Dark media override. The fixture does not own theme tokens.

Public, Client, Agent, and Admin retain one shared component system while their existing profile variables now establish a meaningful order for spacing, panel padding, content rhythm, glass strength, solidity, and depth. The fixture consumes the canonical content-gap variable so comparison cards reveal that profile behavior directly.
